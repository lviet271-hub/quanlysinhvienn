DO AN JAVA - QUAN LY SINH VIEN

YEU CAU:
- JDK 17 hoac moi hon
- VS Code + Extension Pack for Java
- Maven
- SQL Server

1. Mo SQL Server Management Studio, chay file database.sql.
2. Mo file DBConnection.java va sua:
   - URL: ten may/instance va port SQL Server
   - USER: tai khoan SQL Server (vi du sa)
   - PASSWORD: mat khau SQL Server cua ban
3. Mo thu muc QuanLySinhVien trong VS Code.
4. Cho Maven tai thu vien JDBC. Neu duoc hoi, chon "Trust".
5. Mo Main.java va bam Run.

Tai khoan demo:
- Ten dang nhap: admin
- Mat khau: 123456

LUU Y:
- Ngay sinh nhap theo dang yyyy-MM-dd, vi du 2005-08-20.
- Tai khoan demo chi de hoc tap; khong dung mat khau nay cho he thong that.
- Neu SQL Server khong dung localhost:1433, can sua URL cho dung ten instance/port.
